# Fork customization ledger

One entry per customization of upstream, not per commit. The heading is `## custom: <slug>`; the slug is the value of the `Fork-Flow-Change: <slug>` commit trailer. Each entry has these eight fields, once each, in this order, one line each, written `- **<Field>** — <value>` with a nonempty value:

- **What it does** and **Why** — plain sentences.
- **Files** — every upstream file the customization changes, deleted ones included, as backticked, comma-separated paths or git globs (`*` stays inside one directory, `**` recurses), plus the fork-owned files of the same change so a retirement finds them. A fork-owned file (one the upstream base lacks) never needs an entry of its own. A shared file (route tables, locale files, generated files, lockfiles, `CONTEXT.md`) is listed under every entry that changes it, and so is every Markdown doc that describes the customization (`docs/*.md`, `CONTEXT.md`). The exemptions are in `fork-change` step 4.
- **Depends on upstream** — which upstream behavior it rides on, or `none`.
- **Tripwire paths** — backticked, comma-separated upstream paths or globs the port probe reads, or `none` when Depends on upstream is `none`. Each must match a file at `git merge-base HEAD <upstream>`; a typo silently switches the probe off.
- **Must still be true** — observable assertions, no line numbers.
- **Verify** — one fast command (CI's stock runtime for the project's language: no project packages, no dependency install; two seconds at most) that fails with a message naming its assertion when the customization is gone.
- **Check** — the targeted project test for the behavior, run with the **Test one file** command from `.omp/rules/commands.md`, or `none`.

`.fork/check.sh` runs every Verify; the pre-commit and pre-merge-commit hooks, CI and both skills call it. `.fork/check.sh <slug>…` runs chosen Verifies and `.fork/check.sh --check <slug>…` their Checks. `upstream-port` reads Tripwire paths and Must still be true after each release merge. `fork-change` writes and updates entries, proves every new or changed Verify, and retires an entry with `fork-change retire <slug>`. No other line in this file may start with two hashes.

## custom: rtl-and-arabic-locale

- **What it does** — Two halves of the same feature.
